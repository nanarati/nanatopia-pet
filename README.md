# 나나토피아 강아지 (베타)

바탕화면에서 같이 지내는 강아지 친구 — 베타 테스트용 다운로드 저장소입니다.

**[최신 버전 받기 → Releases](https://github.com/nanarati/nanatopia-pet/releases/latest)**

1. `NanatopiaPet-Setup-x.x.x.exe` 를 받아 실행하면 바로 설치되고 강아지가 나옵니다.
2. 처음 실행할 때 "Windows의 PC 보호" 창이 뜨면 **추가 정보 → 실행** 을 눌러 주세요.
3. 새 버전이 나오면 프로그램이 알아서 받아 두었다가, 다음에 켤 때 바뀝니다.
