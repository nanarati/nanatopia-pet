# 나나토피아 강아지 (베타)

바탕화면에서 같이 지내는 강아지 친구 — 베타 테스트용 다운로드 저장소입니다.

**[설치 파일 받기 (항상 최신)](https://github.com/nanarati/nanatopia-pet/raw/main/updates/NanatopiaPet-Setup.exe)**

1. `NanatopiaPet-Setup-x.x.x.exe` 를 받아 실행하면 바로 설치되고 강아지가 나옵니다.
2. 처음 실행할 때 "Windows의 PC 보호" 창이 뜨면 **추가 정보 → 실행** 을 눌러 주세요.
3. 새 버전이 나오면 프로그램이 알아서 받아 두었다가, 다음에 켤 때 바뀝니다.

## 📱 안드로이드 (베타)

**[안드로이드 앱 받기 (APK)](https://github.com/nanarati/nanatopia-pet/raw/main/android/NanatopiaPet.apk)**

1. 휴대폰에서 위 링크를 눌러 받고, 받은 파일을 눌러 설치해요. "출처를 알 수 없는 앱" 허용을 물어보면 허용해 주세요.
2. 앱을 열고 **권한 켜러 가기** → 나나토피아 강아지의 **다른 앱 위에 표시**를 켜요.
3. **바탕화면에 내보내기**를 누르면 강아지가 다른 앱 위를 돌아다녀요.
4. 톡 = 쓰다듬기, 두 번 톡 = 밥, 꾹 = 재주, 끌어서 휙 = 던지기. 알림창에서 밥 주기·숨기기·끄기를 할 수 있어요.
5. 🌙 밤 모드: 앱에서 **탁상 모드**를 켜거나, **화면 보호기**로 정해 두면 충전 중에 까만 화면에서 강아지가 시계와 함께 자요.
